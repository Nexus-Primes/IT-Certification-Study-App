# Reporting a problem

Cert Study is a local study app. It keeps your progress in files on your own computer and has no
account system or server of its own. The only network use in the desktop app is checking GitHub
for a newer version.

If you find a security problem (for example a way for a web page or file to reach your data), please
open a private report through the repository's **Security** tab (Report a vulnerability) rather than
a public issue. For anything else, such as a wrong answer, a bug, or a typo, a normal GitHub issue is
fine.

You will not be asked for any personal data. Please do not attach your progress or backup files to
a report.
